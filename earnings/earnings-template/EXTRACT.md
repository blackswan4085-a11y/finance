# 실적 리포트 자료 정리 규칙

## 작업 경로

작업 루트는 이 폴더의 상위 폴더입니다. 원문은 `자료/<폴더명>/`, 완성 결과는 `결과/<폴더명>/`에 보관합니다. 기존 원문을 덮어쓰지 않습니다. 대화로 받은 원문도 해당 자료 폴더에 저장합니다.

`schema.json`을 읽습니다. JSON 형식이 필요하면 `../결과/V_FY2026Q3/input.snapshot.json`을 참고하되 기존 회사·기간의 내용은 재사용하지 않습니다. 사용자는 원문만 제공하면 되고 AI가 JSON 정리부터 렌더링까지 수행합니다.

## 원문과 재무표

1. 회사명·티커·통화·결산월·보고 분기와 GAAP/Non-GAAP 기준을 확인합니다. 사용자 메모에 명시된 회계 기준도 근거로 보관합니다.
2. `sources`에 실제 파일 경로와 출처 이름을 등록합니다. 컨콜은 문단 번호 사본을 만들어 발언 위치를 추적할 수 있습니다.
3. `reportPeriod.start/end/sourceId`는 원문상 실제 보고 기간을 YYYY-MM-DD로 입력합니다. 회계분기 번호에서 역산하지 않습니다.
4. 금액은 회사 통화의 백만 단위, EPS는 주당 통화, 비율은 퍼센트 값으로 입력합니다. 예: USD 5 billion → 5000.
5. `quarters`는 단일 분기 실적입니다. 부족한 자료를 보간하거나 추정하지 않습니다. 결측은 null, 실제 0은 0입니다.
6. `annuals`에는 완료된 회계연도만 complete:true로 입력합니다. 누적 실적과 미래 추정치는 포함하지 않습니다.
7. `consensus`는 항상 null입니다. 가이던스와 시장 예상치는 사용하지 않습니다.
8. 계산된 YoY/QoQ·서프라이즈·가이던스 차이는 JSON에 직접 넣지 않습니다. 코드가 계산합니다.

## 컨콜 선정과 문체

전체 원문에서 사업별 매출·성장, 물량과 매출의 차이, 비용·일회성 항목, 추세 변화와 회사가 제시한 원인을 확인한 뒤 주요 수치를 선정합니다. 같은 종류의 물량 증가율만 반복하지 않습니다.

- `conferenceCall`에 실제 컨콜 대상 연도·분기·출처를 넣습니다. 발언 중 수치가 지칭하는 기간은 각 항목의 period에 별도로 보관합니다.
- 모든 보고서에서 레이아웃과 관계없이 `operatingDrivers`와 `callMetrics`는 합계 최대 6개입니다. 수주 총계·개별 계약 및 실적 카드의 매출·EPS 반복을 피하고, 관련 수치는 한 항목으로 합쳐 원문 순서로 정리합니다. 이미지에서도 한 항목을 여러 카드로 나누지 않습니다.
- 주가 영역 아래에 '시가총액 조회 시각 · 표시 통화' 문구를 표시하지 않습니다.
- 수치, 단위, 대상 기간, 비교 기준, 발언자, 원문 위치, sourceId를 보관합니다.
- 설명은 최대 두 문장으로 간결하게 작성하고 이미지상 2줄을 권장합니다. 긴 설명은 글자 크기를 유지한 채 카드와 행 높이를 늘려 표시하며, 별도 카드로 나누지 않습니다. '~라고 설명', '~라고 언급' 대신 원인과 변화를 직접 서술합니다.
- `callMetrics.details`의 각 설명 문장에는 글자 수 상한을 두지 않습니다. 원문 사실을 보존하고 불필요한 반복을 줄입니다.
- 평가·추측·투자 의견·핵심 결론·다음 분기 질문을 넣지 않습니다. 원문에 없는 인과관계를 만들지 않습니다.
- `context`에는 원문에 명시된 증가율·비교 기준을 넣습니다. 비교값은 같은 지표·같은 기준에 한정합니다.
- 문장이 길면 원문의 사실을 보존해 요약하거나 항목을 나눕니다. 말줄임표·글씨 축소로 맞추지 않습니다.

## 사용하지 않는 전망 자료

가이던스·컨센서스는 생성하거나 표시하지 않습니다. 스키마 호환을 위해 consensus:null, guidance:[], guidanceNotes:[], marketEstimates:[]를 반환합니다. 컨콜의 주요 사업 수치만 정리합니다.

## 출력

1. `결과/<폴더명>/input.snapshot.json`을 완성합니다.
2. 작업 루트에서 `node earnings-template/render.mjs "결과/<폴더명>/input.snapshot.json" "결과/<폴더명>"`을 실행합니다.
3. 원문과 수치·기간·회계 기준을 대조하고 PNG를 열어 잘림·겹침을 확인합니다. 오류가 있으면 입력 문장을 수정해 다시 출력합니다.
4. 사용자에게 PNG와 결과 폴더 위치를 보여줍니다.

디자인은 확정된 1.8을 사용하며 실적·추이·주가·컨콜을 높이가 늘어나는 한 페이지에 담습니다. 사용자 디자인 변경 요청 없이 렌더러를 바꾸지 않습니다. marketData는 Finance의 수집 코드가 주가·시가총액·시계열과 기준시점을 채웁니다. AI가 시장 가격이나 PER을 추정하지 않습니다. ImageGen으로 보고서를 다시 그리지 않습니다. 맨 아래 출처·단위·USD 문구와 의견·결론·질문을 이미지에 추가하지 않습니다.
