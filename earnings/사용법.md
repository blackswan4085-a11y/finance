# 실적 리포트 사용법

## 대시보드에서 만들기

Finance 루트에서 `python run.py`를 실행하고 첫 화면에서 새 리포트를 만듭니다.
회사·티커·회계연도·분기·회계 기준을 지정하고 매출·영업이익·EPS를 입력합니다.
컨콜 원문은 있는 경우에만 붙여 넣습니다. 없는 자료나 수치는 비워 둡니다.

금액은 선택 통화의 백만 단위, EPS는 주당 통화입니다. 0과 결측을 구별합니다.
완료된 분기·연간 실제 수치와 실제 보고 기간을 사용하며 가이던스·컨센서스는 새 리포트에 표시하지 않습니다.
컨콜이 있으면 Codex CLI로 내용을 정리하고, 수치 계산과 이미지 생성은 고정 코드가 담당합니다.

## 자료와 완성본

```text
earnings/
  자료/<티커>_FY<연도>Q<분기>/   원문·입력 이력
  결과/<티커>_FY<연도>Q<분기>/   입력 JSON·PNG·HTML·렌더링 근거
  earnings-template/           고정 생성기·스키마·자료 정리 규칙
```

보고서 이름 예: `V_FY2026Q3`. 회계연도·분기는 회사 기준입니다.
원문에는 분기별 재무표, 완료된 연간 실적, 컨콜 전문, 통화·회계 기준·보고 기간을 확인할 수 있는 자료를 모읍니다.
이전 결과와 원문은 보존하며 새 대시보드 생성본은 `dashboard/<버전>/`에 저장합니다.
편집 상태와 작업 기록은 Finance의 `earnings_workspace/`에 있습니다.
원문·결과·작업 상태는 Git에 포함하지 않습니다.

## 완성 JSON을 직접 렌더링하기

AI가 원문을 읽고 `earnings-template/EXTRACT.md`와 `schema.json`에 맞춰 JSON을 작성한 뒤,
`earnings/` 폴더에서 실행합니다.

```powershell
node earnings-template/render.mjs "결과/V_FY2026Q3/input.snapshot.json" "결과/V_FY2026Q3"
```

`render.cmd`에는 완성 JSON 파일을 끌어놓을 수도 있습니다. Excel·TXT를 직접 렌더링하는 명령은 아닙니다.
JSON 형식만 참고할 가상 예시는 `../tests/fixtures/earnings.json`에 있습니다. 가상 수치를 실제 보고서에 사용하지 마세요.

실제 자료의 수치·기간·발언·출처를 사용하고, 없는 발언이나 출처를 만들지 않습니다.
디자인 변경 요청이 없으면 생성기·디자인 코드는 수정하지 않습니다.
출력은 이번 분기 실적, 과거 실적 추이, 주가·밸류에이션, 컨콜 주요 수치의 고정 한 페이지입니다.

Node.js, Python Pillow, Windows 맑은 고딕이 필요합니다.
다른 Python을 쓰려면 `EARNINGS_PYTHON`에 실행 파일 경로를 지정합니다.
